# 📱 OFICINA SMART V5 - Management System

![Status](https://img.shields.io/badge/Status-Premium-blueviolet)
![License](https://img.shields.io/badge/License-MIT-green)

**Oficina Smart V5** es una aplicación de gestión financiera de alto rendimiento diseñada para el control de aportes de oficina, servicios de Internet y turnos de agua. Con una estética **"Aurora Premium"**, esta App ofrece una experiencia móvil de lujo tanto en navegador como en Android nativo.

---

## ✨ Características Principales

- 🌌 **Diseño Aurora Pro**: Interfaz basada en Glassmorphism y fondos dinámicos.
- 🌐 **Monitor de Internet**: Seguimiento en tiempo real de metas mensuales (179 Bs) con indicadores visuales de progreso.
- 💧 **Gestión de Agua**: Sistema inteligente que sugiere el turno de pago basado en el historial.
- 📋 **Reportes WhatsApp**: Generación automática de resúmenes financieros con formato profesional listos para compartir.
- 📦 **PWA Ready**: Instalable en cualquier smartphone sin necesidad de tiendas de apps.
- 🤖 **Android Nativo**: Incluye estructura para procesamiento en Android Studio mediante WebView.
- 💾 **Persistencia Local**: No requiere base de datos externa; utiliza `localStorage` para máxima privacidad y velocidad.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend**: HTML5 Semántico, CSS3 Moderno (Variables, Flexbox, Grid).
- **Lógica**: Vanilla JavaScript (ES6+).
- **Gráficos**: [Chart.js](https://www.chartjs.org/) para analítica financiera.
- **Tipografía**: Plus Jakarta Sans & JetBrains Mono via Google Fonts.

---

## 🚀 Cómo empezar

### Opción A: Servidor Local (XAMPP)
1. Clona este repositorio en tu carpeta `htdocs`.
2. Asegúrate de que Apache esté encendido.
3. Accede desde tu navegador a `http://localhost/OFICINA`.

### Opción B: Android Studio
1. Abre la carpeta `PROYECTO_ANDROID` en Android Studio.
2. Sincroniza Gradle.
3. Compila el APK desde el menú `Build`.
